One line: an affectionate roast of the human operator — debugging code at
3 a.m. fueled by instant noodles and pure spite, where honestly the
noodles do most of the work. Savage in the wording, fond at heart.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
